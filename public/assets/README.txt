# Как загрузить свои видео

1. Положите свои рилсы в `public/assets/` с именами:
   - `work1.mp4`, `work2.mp4`, `work3.mp4` (вертикальные)
   - `workhr1.mp4`, `workhr2.mp4`, `workhr3.mp4` (горизонтальные)

2. Для замены фона hero — положите в `public/`:
   - `hero-reel.mp4` (видео-фон)
   - `hero-poster.jpg` (постер)

3. Чтобы изменить названия или ссылки — отредактируйте `src/data/content.ts`
